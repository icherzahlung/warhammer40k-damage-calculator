# Warhammer 40k Damage Calculator

Simple console damage calculator for Warhammer 40,000 written in Python.

## Features

- Calculate hit chance
- Calculate wound chance
- Calculate failed save chance
- Calculate expected damage output

## Requirements

- Python 3

## Run

```bash
python damage_calculator.py
```

## Example

```text
Attacks: 10
Hit roll: 3
Strength: 4
Target Toughness: 4
Target Save: 3
AP: -1
Damage per wound: 1

Expected damage: 2.22
```
